# Glendale Web UI Automation

A **web UI automation project** developed for testing the **Glendale website** using **Java and Selenium WebDriver**.

### Tech Stack

**Java | Selenium WebDriver | TestNG | Maven**

### Coverage

* Website UI validation
* Functional test scenarios
* Page interactions and validations
* Regression testing

**Purpose:** Demonstrate practical web UI automation and test implementation for a real-world website.
